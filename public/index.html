So funktioniert Ideenraum

Doppelklick auf eine freie Stelle startet eine neue Mindmap. Mit Tab und Enter baust du sie Ast für Ast aus, ohne die Maus anzufassen.

Tab
Unterthema zum ausgewählten Knoten
Enter
Geschwister-Thema (beim Bearbeiten: fertig)
⇧ Enter
Zeilenumbruch im Text
Doppelklick / F2
Text bearbeiten
Pfeiltasten
Zwischen Knoten wechseln, andere Elemente verschieben
Knoten ziehen
Auf einen anderen Knoten ablegen, um ihn umzuhängen; ins Leere ziehen löst ihn als eigene Mindmap
Leertaste + Ziehen
Fläche verschieben (auch: mittlere Maustaste, zwei Finger)
⌘ + Scrollen
Zoomen (auch: Pinch auf dem Trackpad)
⇧ 1
Alles anzeigen
⌘ Z / ⇧ ⌘ Z
Rückgängig / Wiederholen
⌘ C V D
Kopieren, Einfügen, Duplizieren
Entf
Auswahl löschen (Knoten samt Unterthemen)
V H M N T R L P
Werkzeuge: Auswählen, Verschieben, Mindmap, Haftnotiz, Text, Form, Verbindung, Stift
Text einfügen
